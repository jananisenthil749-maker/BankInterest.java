# Bank Interest Calculator – Java

## About the Project
This is a simple Java program that demonstrates **Abstraction, Inheritance, and Method Overriding** using an abstract bank class.

The program calculates the principal amount multiplied by the interest rate offered by SBI and PNB banks.

## Technologies Used
- Java
- Scanner Class
- Object-Oriented Programming (OOP)

## Concepts Used
- Abstract Class
- Abstraction
- Inheritance
- Method Overriding
- Runtime Polymorphism

## Bank Interest Rates
- SBI: 7%
- PNB: 8%

## How It Works
1. The user enters the principal amount.
2. The SBI class returns an interest rate of 7%.
3. The PNB class returns an interest rate of 8%.
4. The program calculates and displays the amount multiplied by each bank's interest rate.

## Sample Output

```text
Enter the principal amount
10000
Rate of Interest is: 7%
Principal × Rate = 70000.0
Rate of Interest is: 8%
Principal × Rate = 80000.0
```

## How to Run

1. Install Java JDK.
2. Save the code as `ybank.java`.
3. Open the terminal.
4. Compile the program:

```bash
javac ybank.java
```

5. Run the program:

```bash
java ybank
```
